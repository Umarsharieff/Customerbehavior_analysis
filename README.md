# Customerbehavior_analysis
Data analytics project done on customer behavior data using Python, SQL and power BI to showcase different shopping patterns between age groups, revenues by different factors, categories. 
Used PYTHON to clean the data, did EDA and feature engineering, changed a numerical column of age groups to 4 quartiles, filled null values with median value from respective category instead of using mean to avoid skewing of data.  
Used SQL to answer some business problems. 
Used POWER BI to create a dashboard with slicers, bar charts, cards to show revenue by categories and age groups, sales by category and age groups. Added slicers to create an interactive dashboard to filter by subscribers and non subscribers.
